# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются только для последней версии приложения.
Обновляйтесь до актуальной версии из
[релизов GitHub](https://github.com/overklassniy/STANKIN_Schedule_app/releases),
Google Play или RuStore.

| Версия | Поддержка |
| --- | --- |
| 3.4.x | Да |
| < 3.4 | Нет |

## Сообщение об уязвимости

Не создавайте публичный issue и не раскрывайте детали уязвимости до выхода
исправления.

Сообщить об уязвимости можно:

- через
  [GitHub Security Advisories](https://github.com/overklassniy/STANKIN_Schedule_app/security/advisories/new)
  — предпочтительный способ;
- по почте: s.kiani@stankin.ru.

В сообщении укажите:

- версию приложения и источник установки;
- описание уязвимости и её возможное влияние;
- шаги воспроизведения или proof of concept;
- затронутые данные (например, токен авторизации личного кабинета,
  локальная база данных).

Проект поддерживается в свободное время, поэтому жёстких сроков нет — но мы
подтвердим получение отчёта и постараемся разобраться и выпустить исправление
как можно скорее. Детали уязвимости раскрываются публично только после выхода
исправления.

## Зона внимания

- Авторизация в модульном журнале через `lko.stankin.ru` (OIDC + PKCE
  в WebView) и хранение токена.
- Локальное хранение данных: расписания, оценки журнала, настройки
  (Room, DataStore).
- Разбор внешних данных: импорт расписаний, RSS-ленты, iCal, ответы
  API `stankin.ru`.
- Секреты сборки: `release.keystore`, `google-services.json`,
  `stankin.secret`, `local.properties` не должны попадать в репозиторий
  или публичные артефакты.
